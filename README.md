# 明日方舟 x 诡镇奇谈：莱茵生命调查员扩展包 (Arknights x AHLCG: Rhine Lab Investigator Expansion)

这是一个基于《明日方舟》莱茵生命阵营制作的《诡镇奇谈：卡牌版》（Arkham Horror LCG）同人自定义扩展包。
本项目旨在将莱茵生命的干员们带入阿卡姆的疯狂世界（希望别疯狂），包含全新的调查员、专属支援、专属事件与专属弱点。

本扩展包适用于 **arkham.build** 网页组卡器以及相关的网页版模拟器。推荐将模拟器本地部署来游玩，因为会更改后端文件。

## 🛠️ 安装与使用说明 (Installation & Usage)

###  在 arkham.build / 网页模拟器 中使用
*   下载 `json` 文件夹中的对应文件。
*   在 `arkham.build` 的设置中导入 Fan-made Content。
*   创建卡组。
*   （如果你想要再网页版里有实际效果的游玩，请下载.hs的源码并重新编译后端，或者到已经部署好的网页端游玩）

## 🎨 设计理念 (Design Philosophy)
*   **赫默**：依靠数据与医疗支援，体现学者的冷静与母亲的焦虑。
*   **塞雷娅**：极致的防线，牺牲自己的行动与状态来保护队友，但被“家庭关系”深深束缚。
